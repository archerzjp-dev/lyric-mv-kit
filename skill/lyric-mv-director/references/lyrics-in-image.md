# 歌词做进画面：手法库

规矩先说：**任何时刻，当前这句歌词都要在画面里、在安全区内（四边留 96 像素）、不被挡住、一眼读得出来。** 花样再多，读不出来就是失败。字不能在它被唱出来之前点亮；整句可以提前不超过 0.4 秒以暗色出现（预告）。

默认状态：没唱到的字 30% 亮度，唱到的全亮，正在唱的那个字有一下冲击（`MV.kara.state` 的 `hit`，1 → 0，约 0.12 秒衰减）。

下面每种手法写的是“字跟着什么物理”。挑和这句歌词意思有关的那种，**一句歌词一种做法，不要一句里叠三种。**

## 被外力作用

| 手法 | 做法 | 适合的词 |
|---|---|---|
| 压扁 | 唱到的字纵向弹簧到 35%、横向摊到 125%，上面有东西压下来 | 碾、压、重、坦克、履带 |
| 劈开 | 一道线划过，字沿线错开几像素，两半各自滑走 | 劈、断、裂、越过 |
| 裂纹 | 字上每拍多一批裂缝细线，最后碎成块 | 碎、骨头、崩塌 |
| 剥落 | 用字形内部取点，每拍掉一批碎片，剩空心轮廓 | 斑驳、剥离、褪色 |
| 被淹 | 水位线涨过字的高度，水下的字变暗、冒泡 | 淹没、窒息、沉 |
| 被盖住 | 字唱出 0.5 秒后，一条黑色涂抹条从左到右盖住 | 沉默、审查、藏 |
| 被吹斜 | 字逆着风 skew，越唱越斜，但读得出 | 风、狂沙、顶着 |
| 被同化 | 卡拉 OK 反过来：唱到的字变灰，没唱到的还亮 | 同化、被吞、失去 |

## 自己在动

| 手法 | 做法 | 适合的词 |
|---|---|---|
| 掉落 | 唱到的字旋转、缩小，沿螺旋掉进深处 | 坠落、深渊、跌 |
| 回声 | 唱完后沿弧线生出 3–4 个越来越淡的副本 | 回荡、口号、喊 |
| 燃烧 | 字的边缘发亮，从下往上烧成灰，火星上飘 | 燃烧、火、热血 |
| 抖动 | 只抖一个字，幅度跟人声响度 | 疯、怕、挣扎 |
| 骑在线上 | 字的基线跟着一根会振动的弦起伏 | 线、弦、心跳 |
| 刻 | 竖排，一块墙板刻一个字，墙一拍一块砸上来 | 墙、碑、铁 |

## 尺度对比

| 手法 | 做法 |
|---|---|
| 巨字 | 一个字占半屏，在小节线上砸下来（落点 0 ms 硬切，不缓动），只用歌词原字 |
| 极小的字 | 巨物（齿轮、塔）旁边排三个极小的字：“算什么” |
| 空框 | 字排在一个空的相框/格子里，周围什么都没有 |

## 排版的规矩

- 左对齐到网格（起步工程边距 96）。居中只用于一两个巨字。
- 不要孤字：一句排两行时，最后一行至少两个字。
- 数字和单位不拆行。
- 字和背景的反差要够：暗底上字至少 bone 色的 90%，亮底上字用墨色。
- 竖排时标点要换竖排形式或去掉。

## 预告和收尾

- 一句开始前 0.4 秒，整句以 30% 亮度出现，眼睛先找到位置。
- 一句唱完后至少停留 0.3 秒再离开，句尾的拖音期间字保持亮。
- 两句之间的空隙小于 0.6 秒时，不要做“上一句离场 + 下一句入场”两个动作，直接换。
