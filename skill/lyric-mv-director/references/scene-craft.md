# 写场景

## 一、场景的形状

```js
const scene = {
  init(stage) { /* 只跑一次：预计算点阵、布局、路径。不放任何和时间有关的东西 */ },
  draw(ctx, f) {
    // f.t 歌曲时间，f.lt 场景内时间，f.p 场景进度 0–1，f.W/f.H 是 1920×1080
    ctx.fillStyle = C.ground; ctx.fillRect(0, 0, f.W, f.H); // 先铺满：每帧都要完整覆盖
    // ……
  },
};
```

场景表在 `scenes.js` 末尾：`{ id, start, end, scene }`。切点用歌词和小节线算，不写秒数。

## 二、动作的节奏

- **猛—停—猛**：一次变化用强缓动（`outExpo`、`inOutCubic`、`spring`）在 0.15–0.4 秒内完成，然后**停住**，等下一拍。匀速飘是屏保。
- **要落在拍上的动作提前 40–190 毫秒开始**，让它的“到位”落在拍点上；反应类的动作（震、闪）在拍点后 0–45 毫秒开始。
- **冲击本身是 0 毫秒的硬切**：巨字砸下、切镜头、闪白，在拍点那一帧直接变，不要缓动。缓动会把“砸”变成“滑”。
- **层级**：小节线（强拍）上切镜头或做大的状态变化；底鼓上下沉、震 2–6 像素；军鼓上一阵风或一次闪；踩镲上细小的闪烁。整体能量跟响度包络（`music.energy(t)`）。
- **同一种处理不超过约 6 秒**：再长观众就看腻了。延长一段要换新的处理或者停住，不要把动画放慢。

工具：

```js
music.beatAt(t)            // 连续拍号，3.5 = 第 4 拍的一半
music.barAt(t)             // 连续小节号
music.pulse(t, 'kicks', 0.2)   // 最近一次底鼓后的衰减 1 → 0
music.timeOfBar(k)         // 第 k 个小节线的时间
MV.ease.spring(x, 14, 5)   // 过冲后回弹
MV.noise(x, y, seed)       // 确定的噪声，做风、抖、纸纹
```

## 三、镜头

- canvas 里的“镜头”就是 `ctx.translate/scale`：推近用 `outCubic` 缓入到小节线；冲击缩放 1.03–1.06 然后衰减。
- 一段里最多一次大的镜头运动。镜头和主体不要同时大动。
- 推近到某个东西里面，是最便宜也最有效的转场（推进表盘的轴心 → 下一段从那个圆开始）。

## 四、转场

默认硬切在小节线上。要做转场时，用这支片子自己的“物”：

- 匹配剪：上一段最后的形状 = 下一段第一个形状（圆 → 圆、线 → 线）。
- 劈开：一道线划过画面，沿线裂开滑走，露出下一段。
- 满屏一色：上一段收在整幅纯色，下一段从同一个纯色里长出来。
- 推进：镜头推进某个东西，穿过去。

不要用通用的叠化、百叶窗、故障。

## 五、交接

每两段之间写好交接状态（见 `visual-system.md`），两边的场景都按它写最后一帧/第一帧。分给不同的人或不同的对话做，也能拼成一条。

## 六、性能

- 每帧（一个子帧）控制在 25 毫秒以内：草稿能实时预览，正式渲染不至于跑一整夜。
- 重的东西（几千个点的位置、字形取点、路径）在 `init` 里算好。
- 粒子过万用 `ImageData` 直接写像素，或者换 WebGL（three.js 的做法同理：在 `hf-seek` 里按 t 设好状态再 `renderer.render`）。
- 几个场景共用的东西（塔、格子、裂纹）写成一个带注释接口的共用文件，后面的人直接用。

## 七、运动模糊

HyperFrames 的 `data-motion-blur` 只管 DOM 元素，canvas 里画的东西要自己做：`MV.Stage` 的 `samples` 在快门时间里按几个子时间点各画一遍取平均。

- 草稿 `samples: 1`，正式 8–16。快门 `shutter: 0.5`（半帧）是电影感的默认值。
- 采样数乘在渲染时间上：16 个子帧就是 16 倍。只在快速运动的段落需要高采样时，可以按场景设不同的采样数。
- 子帧必须真的是不同时间的画面：所以第一条规矩（画面是 t 的纯函数）在这里是硬要求。

## 八、和 Claude 一起写

- 一次只做一段。给 Claude 的须知用 `templates/SCENE_BRIEF.md`：这段的歌词、画面、交接状态、能量、用哪些母题。
- 每做完一段，跑 `npx hyperframes snapshot --at` 取这段里 6–8 个时间点（每句第一个字、每个小节线、交接点），看图，不要只看代码。
- 返工时说具体：“2:31 这一帧字太小读不出”“交接处亮点停在 1824 不是 1890”，比“不够炫”有用得多。
