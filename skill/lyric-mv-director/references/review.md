# 审片清单

先出整片联系表（每 2.5 秒一帧，排成网格），再逐段抽全分辨率的帧，再用正常速度戴耳机完整看一遍。每一条都过了才出正式片。

## 读得出

- [ ] 每一句歌词，在它被唱的整个时间里都在画面里、在安全区内、没被挡住
- [ ] 最小的歌词字号在 1080p 下不小于 56 像素（安静段落的小字也一样）
- [ ] 字和背景的反差够：暗底上的灰字、亮底上的浅字最容易出事
- [ ] 没有孤字，没有出画的字，竖排标点正确
- [ ] 歌词和实际演唱一致（多唱、和声、改词处照唱的来；错别字在画面上改正）

## 对得上

- [ ] 抽 8 处，字亮起的那一帧和听到的字头差不超过 2 帧（30 fps 下约 67 毫秒）
- [ ] 小节线上的切镜头真的在小节线上，不是早一拍晚一拍
- [ ] 变速的段落没有漂
- [ ] 静场是静的：不震、不闪

## 一个系统

- [ ] 颜色没有跑出色板（最常见：某种雾、闪光、渐变带出一个色板外的颜色）
- [ ] 强调色一个画面只出现一处
- [ ] 只属于一个时刻的颜色，全片只出现一次
- [ ] 母题每次出现都有意思，且逐段加码
- [ ] 相邻两段的交接状态对得上（位置、颜色、大小）

## 不空、不腻

- [ ] 没有两三秒什么都不发生的空档（静场除外）
- [ ] 没有一种处理连续超过约 6 秒
- [ ] 副歌每次回来都比上一次更强
- [ ] 结尾和开头押韵

## 技术

- [ ] `npx hyperframes check` 没有错误
- [ ] 成片帧数 = 时长 × 帧率，音轨在、时长和歌一致
- [ ] 响度和原歌一致（`npx hyperframes audio 成片.mp4 --only loudness` 对比原歌）
- [ ] 4K 版放大到 1:1 看细线和字边，确认是真 4K 不是放大

## 常见的硬伤

- 安静段落的小字（仿宋 40 像素）在整片里几乎看不见
- 交接处光点/线的位置差几十像素，一切换就跳
- 某段颜色跑出调色板：米灰色的雾、偏色的闪光
- 字下面用“外扩挖空”去保证可读，结果看着像描边
- 粒子太多，压暗了字
- 快速运动没有运动模糊，一卡一卡
